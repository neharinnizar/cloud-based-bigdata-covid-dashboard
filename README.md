# Cloud-Based Big Data Processing and Dashboard on WHO COVID-19 Mortality

## Overview

This project demonstrates an end-to-end cloud-based big data analytics pipeline using WHO COVID-19 mortality data.

The workflow includes data preprocessing using PySpark, cloud storage using AWS S3, and interactive dashboard creation using Power BI.

---

## Technologies Used

- Python
- PySpark
- Apache Spark
- Google Colab
- AWS S3
- Hadoop S3A Connector
- IAM
- Power BI
- Parquet

---

## Project Workflow

1. Load WHO COVID-19 mortality dataset.
2. Clean and preprocess the data using PySpark.
3. Aggregate country-wise, sex-wise, and age-group KPIs.
4. Configure AWS S3 using IAM credentials and Hadoop S3A.
5. Store processed datasets in Parquet format.
6. Build interactive Power BI dashboards.
